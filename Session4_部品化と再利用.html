0. はじめに：DRY原則と関数の役割

プログラミングには"Don't Repeat Yourself"（同じことを繰り返すな）という重要な格言があります（DRY原則）。
同じ計算処理を何度もコピペしていませんか？ コピペはバグの温床です。
処理をひとまとめにして名前をつけ、何度でも呼び出せるようにしたものが「関数」です。

引数 (Input)
関数 (Process)
戻り値 (Output)

関数は「材料」を入れると「成果物」を返してくれる魔法の箱です。

1. 関数 (Function) の基本

定義と呼び出し

関数を作ることを「定義 (Define)」、使うことを「呼び出し (Call)」と言います。

関数の構文

def 関数名(引数1, 引数2, ...):
    """関数の説明（ドキュメント）"""
    実行したい処理
    return 戻り値
# 1. 関数を作る（定義）
def tasizan(a, b):
    answer = a + b
    return answer

# 2. 関数を使う（呼び出し）
# ここで初めて関数の中身が実行される
result = tasizan(3, 5)
print(result)  # 8

# 何度でも使える！引数を変えれば結果も変わる
print(tasizan(100, 200)) # 300

PrintとReturnの決定的違い

初心者が最もつまずくポイントです。この違いを理解しないと、関数を使いこなせません。

機能 print() return
目的 人間に文字を見せるため プログラムに結果を渡すため
再利用 できない（ただの文字表示） できる（変数に入れたり計算に使える）
終了 処理は続く 関数の処理はそこで即終了する 
def bad_add(a, b):
    print(a + b)  # 表示するだけ

def good_add(a, b):
    return a + b  # 値を返す

# printの方は変数に入れても「なし(None)」になる
x = bad_add(10, 20)
# print(x + 5) -> エラー！ Noneと数字は足せない

# returnの方は計算に使える
y = good_add(10, 20)
print(y + 5)   # 35 (OK!)

2. 引数の高度な使い方

デフォルト引数 (Default Arguments)

引数に「初期値」を設定できます。呼び出すときに値を省略すると、初期値が使われます。
「基本設定」と「カスタム設定」を使い分けたいときに便利です。

# taxのデフォルトを1.1(10%)にする
def calc_price(price, tax=1.1):
    return int(price * tax)

print(calc_price(1000))       # 1100 (省略したので1.1が使われる)
print(calc_price(1000, 1.08)) # 1080 (8%を指定)

キーワード引数 (Keyword Arguments)

引数の順番を覚えていなくても、名前を指定して値を渡せます。

def profile(name, age, city):
    print(f"{name}さんは{city}住みの{age}歳です")

# 順番通り
profile("田中", 20, "東京")

# 名前指定なら順番バラバラでもOK！
profile(age=22, city="大阪", name="鈴木")

3. 戻り値の応用

複数の値を返す

Pythonの関数は、カンマで区切ることで複数の値を一度に返せます。

def get_stats(scores):
    return max(scores), min(scores), sum(scores) / len(scores)

# まとめて受け取る
data = [10, 20, 30, 40, 50]
highest, lowest, average = get_stats(data)

print(f"最高:{highest}, 最低:{lowest}, 平均:{average}")

4. スコープ (変数の有効範囲)

ローカル変数とグローバル変数

変数は「どこで生まれたか」によって、使える場所が決まっています。

  • ローカル変数：関数の中で作った変数。関数の外からは見えない。
  • グローバル変数：関数の外で作った変数。どこからでも見える。
points = 100 # グローバル

def game():
    bonus = 50 # ローカル
    print(points) # OK: 外の変数は見える
    
game()
# print(bonus) -> エラー！ 関数の中の変数は外から見えない

安全設計のために

関数の中では、できるだけグローバル変数を使わず、引数で受け取って戻り値で返すようにしましょう。
どの関数がどの変数を書き換えたか分からなくなるバグを防ぐためです。

5. より良いコードを書くために

型ヒント (Type Hints)

Pythonは変数の型を自動判定しますが、明示的に書くことで読みやすくなります（最近の実務では必須級です）。

# 引数はint, 戻り値もint と明示する
def add(a: int, b: int) -> int:
    return a + b

ドキュメンテーション文字列 (Docstring)

関数の直下に """ """ で説明を書くと、関数の説明書になります。

def warikan(total, num):
    """
    割り勘の計算をする関数
    total: 合計金額
    num: 人数
    return: 一人当たりの金額
    """
    return total // num

6. モジュール (Module)

巨人の肩に乗る

Pythonには「標準ライブラリ」と呼ばれる便利な道具箱が最初から入っています。

Randomモジュール（乱数）

import random

# サイコロ
print(random.randint(1, 6))

# ランダム選択
fruits = ["りんご", "みかん", "ぶどう"]
print(random.choice(fruits))

# シャッフル
numbers = [1, 2, 3, 4, 5]
random.shuffle(numbers)
print(numbers)

Mathモジュール（数学）

import math

print(math.pi)       # 円周率
print(math.sqrt(25)) # ルート
print(math.ceil(4.2)) # 切り上げ -> 5

Datetimeモジュール（日付と時間）

ログを取ったり、経過時間を測るのに使います。

import datetime

now = datetime.datetime.now()
print(now)              # 2023-10-05 12:34:56.789
print(now.year)         # 年だけ取得
print(now.strftime("%Y年%m月%d日")) # フォーマット変換

課題3：ガチャシミュレータ（モジュール活用）

リスト ["N", "R", "SR", "SSR"] からランダムに1つ排出する関数 gacha を作ってください。
さらに、for文を使ってこのガチャを10回回し、出た結果をすべて表示するプログラムを書いてください。

解答例を表示する

課題1

def analyze_list(numbers):
    total = sum(numbers)
    avg = total / len(numbers)
    maximum = max(numbers)
    return total, avg, maximum

data = [10, 50, 20, 30, 40]
t, a, m = analyze_list(data)
print(f"合計:{t}, 平均:{a}, 最大:{m}")

課題2

def attack(attack_power, critical=1.0):
    return int(attack_power * critical)

print(f"通常攻撃: {attack(100)}")
print(f"会心の一撃: {attack(100, 1.5)}")

課題3

import random

def gacha():
    rarity = ["N", "R", "SR", "SSR"]
    # 重み付け抽選（choices）を使うと確率を変えられる（発展）
    # 今回は単純なchoiceを使用
    return random.choice(rarity)

print("--- 10連ガチャ ---")
for i in range(10):
    result = gacha()
    print(f"{i+1}回目: {result}")

プログラムの制御

条件分岐とループで「アルゴリズム」を構築する

0. はじめに：プログラムに「脳」を与える

第1回で学んだプログラムは、上から下へ一本道で進むだけでした。しかし、これでは「電卓」と変わりません。
高度なプログラムには、状況に応じた「判断」と、大量のデータを処理する「繰り返し」が必要です。

入力
判断 (If)
繰り返し (Loop)
出力

今回は、プログラミングの核心部分である「制御構造」を学びます。ここをマスターすれば、簡単なAIやゲームのロジックを作れるようになります。

1. 比較演算子と真偽値

正しいか、間違いか

条件分岐を行うためには、コンピュータに「条件」を伝える必要があります。
コンピュータに質問をすると、True（はい、真）または False（いいえ、偽）という「ブール値 (Boolean)」で答えてくれます。

記号 意味 コード例 (x=10) 結果
== 等しい x == 10 True
!= 等しくない x != 5 True
> より大きい x > 20 False
< より小さい x < 5 False
>= 以上 x >= 10 True
<= 以下 x <= 10 True

注意：イコールは2つ！

初心者が最もよくやる間違いです。

  • = (イコール1つ)：代入（右の値を左に入れる）
  • == (イコール2つ)：比較（左右が等しいか確認する）

2. 論理演算子 (Logical Operators)

複数の条件を組み合わせる

現実世界では「土曜日 かつ 晴れ なら遊びに行く」「スマホ または 財布があれば外出できる」のように、複数の条件を組み合わせることがよくあります。
Pythonでは and, or, not を使います。

演算子 意味 例 説明
and 〜かつ〜 A and B AとBが両方TrueならTrue
or 〜または〜 A or B AとBのどちらか一方でもTrueならTrue
not 〜ではない（反転） not A AがTrueならFalse、FalseならTrue 
age = 20
has_ticket = True

# 「20歳以上」かつ「チケットを持っている」
if age >= 18 and has_ticket:
    print("入場できます")
else:
    print("入場できません")

3. 条件分岐 (If Statement)

もし〜なら、こうする

条件によって実行する処理を切り替える構文です。

If文の構文

if 条件式:
    条件が True のときの処理
    (インデントが必要！)
else:
    条件が False のときの処理

Pythonでは、インデント（字下げ）が非常に重要です。条件の中身は、Tabキーまたはスペース4つ分右にずらす必要があります。これが「ブロック（処理のかたまり）」を表します。

score = 85

if score >= 60:
    print("合格です！")
    print("おめでとう！")
else:
    print("不合格です...")
    print("再テストを受けましょう")

print("判定終了")  # これはifの外なので必ず実行される

3つ以上の分岐 (elif)

「Aなら...、Bなら...、それ以外なら...」と分岐を増やしたいときは elif (else ifの略) を使います。

score = 75

if score >= 90:
    print("評価：S")
elif score >= 70:
    print("評価：B")  # ここが実行される
elif score >= 60:
    print("評価：C")
else:
    print("評価：D")

入れ子のIf文 (Nested If)

If文の中にさらにIf文を入れることもできます。

age = 20
has_id = False

if age >= 20:
    if has_id:
        print("お酒を販売できます")
    else:
        print("年齢確認書類が必要です")
else:
    print("お酒は販売できません")

4. 繰り返し (For Loop)

決まった回数のループ

「100回計算する」「リスト全員にメールを送る」といった処理にはループを使います。

For文の構文

for 変数 in range(回数):
    繰り返したい処理

range関数の使い方（詳細）

range() は、連続した数字を作り出す魔法の関数です。3つの書き方があります。

  • range(終了): 0 から 終了-1 まで
    例: range(3) → 0, 1, 2
  • range(開始, 終了): 開始 から 終了-1 まで
    例: range(1, 5) → 1, 2, 3, 4
  • range(開始, 終了, 増分): 数字を飛ばしながら
    例: range(1, 10, 2) → 1, 3, 5, 7, 9
# 3回繰り返す
for i in range(3):
    print(f"{i}回目のハロー！")

合計値を計算する (Accumulator)

ループの中で変数を更新していくことで、合計値を計算できます。

total = 0  # 合計を入れる箱を空(0)にしておく

for i in range(1, 101):  # 1から100まで
    total = total + i

print(f"1から100までの合計: {total}")

5. 条件による繰り返し (While Loop)

〜の間、繰り返す

回数が決まっておらず、「条件が満たされている間はずっと繰り返す」という場合は while 文を使います。
ゲームのメインループや、正しい入力があるまで待つ処理などに使われます。

hp = 3  # 体力

while hp > 0:
    print(f"勇者は戦っている (HP: {hp})")
    hp = hp - 1  # ダメージを受ける

print("勇者は倒れた...")

無限ループに注意！

while 文を使うときは、いつか必ず条件が False になるようにする必要があります。
条件が変わらないと、プログラムが永遠に止まらなくなります（無限ループ）。

6. ループの制御 (Break & Continue)

ループの流れを変える

ループの途中で強制終了したり、スキップしたりするための命令です。

  • break: ループをその場で中断して脱出する。
  • continue: 今回の処理をスキップして、次のループへ進む。
# breakの例：5が見つかったら終了
for i in range(1, 11):
    if i == 5:
        print("5を見つけました！終了します。")
        break
    print(i)

# continueの例：3の倍数をスキップ
for i in range(1, 6):
    if i % 3 == 0:
        continue  # 下のprintは実行されずに次へ
    print(i)

第2回 演習課題

課題1：FizzBuzz（フィズバズ）問題

1から20までの数字を順番に表示するプログラムを作成してください。
ただし、以下の特別ルールを適用してください。

  • 数字が3の倍数のときは、数字の代わりに "Fizz" と表示する。
  • 数字が5の倍数のときは、数字の代わりに "Buzz" と表示する。
  • （応用）両方の倍数（15など）のときは "FizzBuzz" と表示する。

ヒント： i % 3 == 0 で割り切れるか判定できます。

課題2：パスワード認証（応用）

while 文を使って、正しいパスワード（例: "python123"）が入力されるまで、「パスワードを入力してください」と聞き続けるプログラムを作成してください。
正解したら「ログイン成功！」と表示して終了します。

解答例を表示する

課題1 (FizzBuzz)

for i in range(1, 21):
    # 先に一番条件が厳しい「15の倍数」をチェックする
    if i % 15 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)

課題2 (パスワード)

secret = "python123"

while True:  # 無限ループ
    user_input = input("パスワードを入力: ")
    
    if user_input == secret:
        print("ログイン成功！")
        break  # 正解ならループを抜ける
    else:
        print("違います。もう一度。")

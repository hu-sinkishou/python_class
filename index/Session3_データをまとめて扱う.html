第3回

データをまとめて扱う

リストと辞書で大量のデータを管理する

0. はじめに：変数1つじゃ足りない！

「テストの点数」を管理することを想像してください。生徒が3人なら score1, score2, score3 でいいかもしれません。
しかし、生徒が100人いたら？変数を100個作るのは現実的ではありませんし、平均点を計算するコードも長くなってしまいます。

そこで登場するのが、複数のデータをひとまとめにして管理する「コレクション（リスト、辞書）」です。

1. リスト (List)

整理番号つきのロッカー

リストは、データを一列に並べて管理する仕組みです。角括弧 [ ] を使って定義します。
リストの中には、数値、文字列、さらには別のリストまで、何でも入れられます。

# 文字列のリスト
members = ["佐藤", "鈴木", "高橋", "田中"]

# 数値のリスト
scores = [80, 90, 75, 60]

# 混合リスト（PythonならOK！）
data = ["Taro", 19, 175.5, True]

データの取り出し（インデックス）

リストの中身を取り出すには、「何番目か（インデックス）」を指定します。

0から始まる！

プログラミングの世界では、数は0から数えます。
1番目のデータを取り出すには [0] を指定します。

print(members[0])  # 佐藤
print(members[1])  # 鈴木
print(members[2])  # 高橋

# 後ろから数える（マイナスインデックス）
print(members[-1]) # 田中（一番後ろ）
print(members[-2]) # 高橋（後ろから2番目）

リストの操作（スライス・追加・削除）

リストは非常に柔軟です。後からデータを加工できます。

# 追加 (append)
members.append("渡辺")

# 削除 (remove)
members.remove("鈴木")

# 長さを調べる (len)
print(len(members))  # 4

# スライス（切り取り）[開始:終了]
# 終了インデックスは含まれないことに注意！
top3 = members[0:3]  # 0, 1, 2番目を取得

便利な関数

数値のリストに対しては、便利な集計関数が使えます。

nums = [10, 20, 30, 40, 50]

print(max(nums))  # 最大値: 50
print(min(nums))  # 最小値: 10
print(sum(nums))  # 合計: 150

2. リストとFor文の最強コンボ

全データを一括処理

「リストの中身を、先頭から順に変数に入れて処理する」。これはプログラミングで最も頻出するパターンです。
range() を使う必要はありません。リストをそのまま in の後ろに置くだけです。

リストループの構文

for 変数 in リスト:
    変数を使った処理
prices = [100, 200, 150, 300]
total = 0

for p in prices:
    print(f"現在の商品: {p}円")
    total = total + p

print(f"--- 合計金額: {total}円 ---")

3. 辞書 (Dictionary)

名前（キー）で管理する

リストは「番号」で管理しましたが、辞書は「名前（キー）」と「値（バリュー）」のペアで管理します。
「佐藤さんの点数は？」「田中の電話番号は？」といった検索に適しています。

# 辞書の作成 {キー: 値}
student = {
    "name": "山田太郎",
    "age": 19,
    "univ": "A大学",
    "scores": [80, 90, 70]  # 値にはリストも入れられる
}

# キーを指定して取り出す
print(student["name"])  # 山田太郎
print(student["univ"])  # A大学

# 存在しないキーを指定するとエラーになる！
# print(student["weight"]) -> KeyError

データの追加・変更・削除

# 新しいデータを追加
student["weight"] = 65

# 既存のデータを変更（上書き）
student["age"] = 20

# データの削除
del student["univ"]

辞書のループ処理

キーと値をセットで取り出すには .items() を使います。

menu = {"カレー": 500, "ラーメン": 600, "うどん": 400}

for name, price in menu.items():
    print(f"{name} は {price} 円です")

4. （発展）タプル (Tuple)

変更できないリスト

リストと似ていますが、[ ] ではなく ( ) を使います。
一度作ったら中身を変更（追加・削除・代入）できないのが特徴です。

「座標(x, y)」や「RGBカラー(255, 0, 0)」など、変わってはいけないデータの管理に使います。

pos = (100, 200)
print(pos[0]) # 100

# pos[0] = 50 -> エラーになる！

第3回 演習課題

課題1：奇数の抽出
numbers = [3, 10, 5, 8, 2, 7, 1] というリストがあります。
この中から「奇数」だけを取り出して表示してください。

課題2：合計金額の計算（辞書活用）
商品価格表（辞書）があります。
items = {"りんご": 150, "みかん": 100, "バナナ": 200}
このお店で、「りんご2個」と「バナナ3個」を買いました。合計金額を計算して表示してください。

課題3：平均点（リスト関数）
points = [80, 75, 90, 60, 100]
この点数リストの「合計点」「平均点」「最高点」をそれぞれ計算して表示してください。
※平均点は sum() と len() を使って計算できます。

解答例を表示する

課題1

numbers = [3, 10, 5, 8, 2, 7, 1]
for n in numbers:
    # 2で割った余りが1なら奇数
    if n % 2 == 1:
        print(n)

課題2

items = {"りんご": 150, "みかん": 100, "バナナ": 200}

# 価格を取り出して個数を掛ける
total = (items["りんご"] * 2) + (items["バナナ"] * 3)

print(f"合計: {total}円")

課題3

points = [80, 75, 90, 60, 100]

total = sum(points)
avg = total / len(points)
max_score = max(points)

print(f"合計: {total}")
print(f"平均: {avg}")
print(f"最高: {max_score}")

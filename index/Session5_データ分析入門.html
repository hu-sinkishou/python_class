0. はじめに：Pythonが最強である理由

なぜ世界中のデータサイエンティストがPythonを使うのでしょうか？
その答えの一つが、今回学ぶライブラリ Pandas（パンダス） です。

Excelでは100万行を超えると動作が重くなりますが、Pandasなら数百万行のデータも一瞬で読み込み、集計し、加工することができます。
ビッグデータ時代の必須スキルを身につけましょう。

1. Pandasをはじめよう

インポートとDataFrame

Pandasを使うにはインポートが必要です。慣例として pd という名前をつけます。

import pandas as pd

CSVファイルの読み込み

データ分析は、外部ファイル（CSV）を読み込むことから始まります。

# CSVを読み込んで変数 df に入れる
df = pd.read_csv("sales_data.csv")

# データの確認（必須！）
print(df.head())      # 先頭5行を表示
print(df.tail())      # 末尾5行を表示
print(df.shape)       # (行数, 列数) を確認

データの要約 (Describe)

データの傾向を一発で掴むための魔法のコマンドです。

# 平均、最大、最小などをまとめて表示
print(df.describe())

2. データの抽出 (Filtering)

条件に合う行を探す

「1000円以上の商品」や「東京支店のデータ」など、特定のデータだけを取り出します。
これをブールインデックス参照と呼びます。

抽出の構文

新しいdf = df[ 条件式 ]
# 1. 価格が1000以上の行だけ抽出
high_price = df[df['price'] >= 1000]

# 2. 商品名が 'Apple' の行だけ抽出
apples = df[df['product'] == 'Apple']

# 3. 複数条件：価格が1000以上 かつ(&) 在庫があり
target = df[(df['price'] >= 1000) & (df['stock'] > 0)]

3. データの加工と集計

列の計算

Excelのように、列同士を計算して新しい列を作ることができます。
for文を使う必要はありません。Pandasが自動的に全行計算してくれます（ベクトル演算）。

# 売上 = 価格 * 個数
df['sales'] = df['price'] * df['quantity']

# 消費税込み価格を作る
df['tax_price'] = df['price'] * 1.1

グループ化集計 (Group By)

「商品ごとの売上合計」や「日付ごとの平均気温」など、カテゴリごとに集計します。

集計の構文

df.groupby('グループ化する列')['集計する列'].計算方法()
  • .sum() : 合計
  • .mean() : 平均
  • .max() : 最大値
  • .count() : データの個数
# 商品カテゴリ(Category)ごとの、売上(Sales)の、合計
summary = df.groupby('Category')['Sales'].sum()

print(summary)

データの並び替え (Sort)

# 売上が高い順に並び替え
# ascending=False で降順（大きい順）
sorted_df = df.sort_values('Sales', ascending=False)

4. （発展）欠損値の処理

データが空っぽ？

現実のデータは汚いです。入力漏れなどでデータが入っていない（NaN: Not a Number）ことがよくあります。

# 欠損値があるかチェック
print(df.isnull().sum())

# 欠損値を含む行を削除する
clean_df = df.dropna()

# 欠損値を0で埋める
filled_df = df.fillna(0)

第5回 演習課題

仮想売上データの分析

以下のコードを実行して、ダミーデータを作成してから問題に取り組んでください。

import pandas as pd
data = {
    'Date': ['2023-01-01', '2023-01-01', '2023-01-02', '2023-01-02', '2023-01-03'],
    'Product': ['Apple', 'Banana', 'Apple', 'Orange', 'Banana'],
    'Price': [100, 200, 100, 300, 200],
    'Quantity': [5, 2, 3, 1, 4],
    'Region': ['Tokyo', 'Osaka', 'Tokyo', 'Tokyo', 'Osaka']
}
df = pd.DataFrame(data)

問題1：売上列の追加
Price と Quantity を掛け算して、新しい列 Total を作ってください。

問題2：地域別分析
Region（地域）ごとの売上合計(Total)を計算して表示してください。

問題3：高額商品の抽出
売上(Total)が 500円 以上の取引データだけを抽出して表示してください。

解答例を表示する 
# 問題1
df['Total'] = df['Price'] * df['Quantity']
print("--- データフレーム ---")
print(df)

# 問題2
region_sum = df.groupby('Region')['Total'].sum()
print("\n--- 地域別売上 ---")
print(region_sum)

# 問題3
high_sales = df[df['Total'] >= 500]
print("\n--- 高額取引 ---")
print(high_sales)

最終課題

売上データ分析アプリケーションの開発

Mission Start

これまでに学んだすべての知識を総動員して、
実践的なデータ分析ツールを作り上げてください。

1. 課題の要件

以下の機能を持つGUIアプリケーションを作成し、提出してください。

必須機能リスト

  1. CSV読み込み機能
    • ファイル選択ダイアログを使って、PC内の任意のCSVファイルを選択できること。
    • 選択したファイル名が画面に表示されること。
  2. データ集計機能
    • 読み込んだデータをPandasで集計すること（例：商品ごとの売上合計）。
  3. グラフ表示機能
    • 集計結果をMatplotlibでグラフ化し、Tkinterのウィンドウ内に埋め込んで表示すること。

2. 開発ガイド (Step by Step)

いきなり全部書こうとすると混乱します。以下の手順でブロックごとに実装していきましょう。

Step 1: 画面の骨組みを作る

まずは機能を持たない、見た目だけのGUIを作ります。

  • ウィンドウの作成 (Tk, geometry)
  • 「ファイル選択」ボタンの配置
  • 「グラフ表示」ボタンの配置
  • グラフを表示するためのエリア確保 (Frame)
Step 2: ファイル選択の実装

filedialog モジュールを使います。

from tkinter import filedialog

def open_file():
    filepath = filedialog.askopenfilename(filetypes=[("CSV Files", "*.csv")])
    if filepath:
        # ここでPandasで読み込む処理を書く
        print(f"選択されたファイル: {filepath}")
Step 3: グラフの埋め込み (最難関)

MatplotlibのグラフをTkinterに貼るには、特別な呪文が必要です。

from matplotlib.backends.backend_tkagg import FigureCanvasTkAgg
import matplotlib.pyplot as plt

# グラフを描く領域（Figure）を作る
fig, ax = plt.subplots()

# Tkinter用のキャンバスに変換して配置
canvas = FigureCanvasTkAgg(fig, master=root)
canvas.get_tk_widget().pack()

# グラフを描画するとき
ax.bar(x, y)
canvas.draw()

3. 評価基準 (Rubric)

成績評価（S/A/B/C）は以下の基準で行います。

評価 基準
S (100点) 完璧＋α
エラー処理（ファイル未選択時の対策など）が入っている。
グラフの種類を選べる、集計方法を変えられる等の独自機能がある。
A (90点) 要件達成
CSV読み込み → 集計 → グラフ表示 までの一連の流れがエラーなく動作する。
B (80点) 基本動作

C (60点) 努力圏

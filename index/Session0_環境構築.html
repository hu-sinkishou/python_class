1. Google Colaboratory (前半用)

Googleが提供する、ブラウザ上でPythonを実行できるサービスです。面倒な環境構築が一切不要で、Googleアカウントさえあればすぐに始められます。

スタートアップガイド

使い方の基本は、公式の「Colaboratory へようこそ」ノートブックを見るのが最も確実です。以下のリンクからアクセスし、実際にコードを実行してみてください。

Google Colab にアクセスする

導入ステップ

  1. Googleアカウント（Gmail）を用意し、ログインする。
  2. Google Colaboratory にアクセスする。
  3. 「ノートブックを新規作成」をクリックする。
  4. 表示されたセルに print("Hello") と入力し、左側の再生ボタン（▶）を押す。
  5. 結果が表示されれば準備完了です！

2. ローカル環境 (後半用)

第6回以降のGUIアプリ開発（Tkinter）では、画面を描画するために自分のPC上でPythonを動かす必要があります。
コードを書くためのエディタ VS Code (Visual Studio Code) と、プログラムを動かす Python本体 をインストールします。

重要： WindowsとMacで手順が異なります。必ず自分のOSに合った方法で行ってください。
Step 1: VS Codeのインストール

世界で最も使われている高機能エディタです。以下の公式サイトからダウンロードしてインストールしてください。

VS Code 公式サイトへ

※トップページの「Download」ボタンをクリックし、インストーラーを実行して「次へ」を押していけば完了です。

Step 2: Pythonのインストール

Python本体のインストールは、設定ミスを防ぐために「Python Japan」の公式ガイドに従うのが最も確実です。

Windowsの手順を見る Macの手順を見る

導入チェックリスト

インストールが完了したら、VS Codeを使って動作確認を行います。

  1. VS Codeの起動： インストールした Visual Studio Code を開きます。
  2. 拡張機能の準備： 左側のブロックアイコン（拡張機能）をクリックし、「Python」と検索して Microsoft製の拡張機能をインストールします。
  3. ファイルの作成： メニューの「ファイル」>「新しいテキストファイル」を選択し、hello.py という名前で保存します。
  4. コードの記述： ファイルに以下のコードを書きます。
    import tkinter
    print("OK")
  5. ターミナルで実行：
    • メニューの「ターミナル」>「新しいターミナル」をクリックして、画面下にターミナルパネルを開きます。
    • 以下のコマンドを入力して Enterキー を押します。
      Windowsの場合: python hello.py
      Macの場合: python3 hello.py
  6. エラーが出ずに「OK」と表示されれば、環境構築は成功です！

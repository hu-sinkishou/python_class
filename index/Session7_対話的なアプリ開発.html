0. はじめに：アプリに命を吹き込む

前回作ったウィンドウは、ボタンを押しても何も起きない「張りぼて」でした。
今回は、「ボタンを押したら計算する」「入力された名前を表示する」といった動作（ロジック）を実装します。

「何かが起きたとき（イベント）に、特定の処理（関数）を実行する」という仕組みをイベント駆動 (Event Driven) と呼びます。

1. イベント処理 (Event Handling)

ボタンに関数をバインドする

ボタンを作るときに command=関数名 というオプションを指定すると、クリック時にその関数が実行されます。

括弧をつけてはいけない！

間違い： command=hello()
これだと、アプリが起動した瞬間に勝手に実行されてしまい、ボタンを押しても反応しなくなります。

正解： command=hello
「この関数を使ってね」と名前だけを渡すのがルールです。

import tkinter as tk

# 実行したい関数を先に定義する
def say_hello():
    print("こんにちは！ボタンが押されました")

root = tk.Tk()

# commandに関数名を渡す
btn = tk.Button(root, text="挨拶する", command=say_hello)
btn.pack(pady=20)

root.mainloop()

2. 画面の更新 (Config)

ラベルの内容を書き換える

print() は開発者用のコンソールに表示されるだけで、アプリの画面には出ません。
アプリ画面の文字を変えるには、ウィジェットの .config() メソッドを使います。

import tkinter as tk

count = 0

def count_up():
    global count # 関数の外の変数を書き換える宣言
    count = count + 1
    # ラベルのtextオプションを書き換える
    label.config(text=f"カウント: {count}")

root = tk.Tk()

label = tk.Label(root, text="カウント: 0", font=("Arial", 20))
label.pack(pady=10)

btn = tk.Button(root, text="増やす", command=count_up)
btn.pack()

root.mainloop()

3. ユーザー入力の取得

Entryウィジェット

入力欄から文字を取得するには .get() メソッドを使います。
ここでも「取得した値はすべて文字列」というルールがあるので、計算時は int() 変換が必要です。

エラー対策 (Try-Except)

GUIアプリは、ユーザーがどんな操作をするか予測できません。数字入力欄に「あいう」と入れられるかもしれません。
エラーでアプリが強制終了（クラッシュ）しないように、try-except で守ります。

def calc_double():
    text = entry.get() # 入力を取得
    
    try:
        # 数値変換に挑戦
        val = int(text)
        result = val * 2
        lbl_result.config(text=f"結果: {result}", fg="black")
    except ValueError:
        # 変換に失敗した場合の処理
        lbl_result.config(text="エラー: 数字を入力してください！", fg="red")

root = tk.Tk()
entry = tk.Entry(root)
entry.pack()

btn = tk.Button(root, text="2倍にする", command=calc_double)
btn.pack()

lbl_result = tk.Label(root, text="結果: -")
lbl_result.pack()

root.mainloop()

4. メッセージボックス

ポップアップを表示する

処理の完了やエラーを通知するために、ポップアップウィンドウ（メッセージボックス）を使います。

def show_msg():

第7回 演習課題

課題1：足し算アプリ

2つの入力欄(Entry)と1つのボタンを用意してください。
ボタンを押すと、2つの数字を足した結果をラベルに表示してください。

課題2：ログイン画面（応用）

パスワード入力欄を作成し、ボタンを押したときに「python」と入力されていれば「ログイン成功」、そうでなければ「パスワードが違います」とメッセージボックスで表示してください。

解答例を表示する

課題1

import tkinter as tk

def add():
    try:
        v1 = int(e1.get())
        v2 = int(e2.get())
        lbl.config(text=f"合計: {v1 + v2}")
    except ValueError:
        lbl.config(text="数字を入力してください")

root = tk.Tk()
e1 = tk.Entry(root); e1.pack()
e2 = tk.Entry(root); e2.pack()
tk.Button(root, text="足す", command=add).pack()
lbl = tk.Label(root, text="合計: 0"); lbl.pack()
root.mainloop()

課題2

import tkinter as tk
from tkinter import messagebox

def login():
    password = entry.get()
    if password == "python":
        messagebox.showinfo("成功", "ログイン成功！")
    else:
        messagebox.showerror("失敗", "パスワードが違います")

root = tk.Tk()
tk.Label(root, text="パスワード:").pack()
entry = tk.Entry(root, show="*") # 文字を隠す
entry.pack()
tk.Button(root, text="ログイン", command=login).pack()
root.mainloop()

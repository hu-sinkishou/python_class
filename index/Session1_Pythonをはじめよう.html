Pythonをはじめよう

変数、データ型、そして入出力の世界へ

0. はじめに：なぜPythonなのか？

プログラミング言語には「C言語」「Java」「JavaScript」など数多くの種類がありますが、なぜ大学の初等教育でPython（パイソン）が選ばれるのでしょうか？

Pythonの3つの強み

  • 読みやすい：英文法に近く、初心者でもコードの意味が直感的に理解しやすい。
  • 汎用性が高い：Webアプリ、ゲーム、AI、データ分析、ロボット制御まで何でも作れる。
  • ライブラリが豊富：世界中の天才たちが作った「便利な道具箱（ライブラリ）」が無料で使える。

今回は、この強力なツールを使ってコンピュータと対話する第一歩を踏み出します。

1. 画面への表示 (Print)

Hello, World!

プログラミングの第一歩は、画面に文字を表示させることです。print() 関数を使います。

# 文字列 (String) - クォーテーションで囲む
print("Hello, Python!")
print('こんにちは、世界')

# 数値 (Number) - そのまま書く
print(100)
print(3.14)

# 計算式 - 計算結果が表示される
print(10 + 20)      # 30
print(100 * 1.1)    # 110.0

クォーテーションの罠

以下の違いに注目してください。

  • print(1 + 1) → 2 （数値の足し算）
  • print("1" + "1") → 11 （文字の結合）

"" で囲むと、数字であっても「文字」として扱われます。

2. 変数 (Variables)

データを入れる「名前付きの箱」

プログラムの中で、計算結果や文字を一時的に保存しておく場所を「変数（へんすう）」と呼びます。

変数のルール

  1. 変数名 = 値 で代入する。（右から左へ！）
  2. 変数名は「英小文字」と「アンダースコア」を使うのが一般的（例：user_name）。
  3. 数字から始まる名前はつけられない（例：1st_place はNG）。
# 代入（箱に入れる）
apple_price = 100
count = 3

# 計算に使う
total_price = apple_price * count

# 表示する
print(total_price)  # 300

変数の上書き

変数はその名の通り「変わる数」です。中身を入れ替えることができます。

hp = 100
print(hp)  # 100

hp = 50    # ダメージを受けた！
print(hp)  # 50

hp = hp + 20 # 回復した！
print(hp)    # 70

3. データ型 (Data Types)

コンピュータにとっての「種類」

人間は「10」も「あ」も同じように文字として認識しますが、コンピュータは厳密に区別します。

型名 (Type) 説明 例
int (Integer) 整数。個数や回数などの計算に使う。 10, -5, 0
float 浮動小数点数（小数）。精密な計算に使う。 3.14, 0.01, -2.5
str (String) 文字列。名前やメッセージの表示に使う。 "Hello", 'あいう'

データの型を調べたいときは type() 関数を使います。

print(type(10))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("Hello"))  # <class 'str'>

4. 演算とf-strings

算術演算子

Pythonは高性能な電卓としても使えます。

  • +, -, *, / : 基本の四則演算
  • // : 割り算の「商」（整数部分）
  • % : 割り算の「余り」（剰余）
  • ** : べき乗（2乗、3乗など）
print(10 / 3)   # 3.33333...
print(10 // 3)  # 3
print(10 % 3)   # 1
print(2 ** 3)   # 8 (2の3乗)

f-strings（フォーマット文字列）

変数の値を文章の中に埋め込みたいとき、昔は面倒な結合処理が必要でしたが、今は f-strings があります。
文字列の前に f をつけ、変数を { } で囲むだけです。

name = "田中"
age = 19
height = 175.5

# fをつけると { } の中身が展開される
print(f"私は {name} です。年齢は {age} 歳です。")
print(f"身長は {height} cmです。")

5. ユーザー入力 (Input)

対話的なプログラムへ

プログラム実行中に、ユーザーに値を入力してもらうには input() を使います。

Inputの最大の罠

input() で受け取ったデータは、全て「文字列(str)」になります。
たとえキーボードで「100」と打っても、コンピュータは「イチ・ゼロ・ゼロという文字」として受け取ります。
計算に使いたい場合は、int() や float() で変換（キャスト）する必要があります。

# 文字列として受け取る
name = input("あなたの名前は？: ")
print(f"ようこそ、{name}さん！")

# 数値として受け取りたい場合
age_str = input("年齢を入力してください: ")
# 変換する
age = int(age_str) 

print(f"来年は {age + 1} 歳ですね。")

第1回 演習課題

課題1：自己紹介カード

input を使って「名前」「出身地」「好きな食べ物」を入力させ、最後に以下のようにまとめて表示するプログラムを作成してください。

（出力例）
-- 自己紹介 --
名前：山田太郎
出身：東京都
好物：ラーメン

課題2：BMI計算機

身長(cm)と体重(kg)を入力させ、BMIを計算して表示してください。
計算式：$$ \text{BMI} = \frac{\text{体重(kg)}}{(\text{身長(m)} \times \text{身長(m)})} $$

※ 入力された身長はcmなので、mに直す（100で割る）のを忘れずに！

解答例を表示する

課題1の解答

name = input("名前: ")
place = input("出身: ")
food = input("好物: ")

print("-- 自己紹介 --")
print(f"名前：{name}")
print(f"出身：{place}")
print(f"好物：{food}")

課題2の解答

# 入力を受け取って float(小数) に変換
h_cm = float(input("身長(cm): "))
w_kg = float(input("体重(kg): "))

# cmをmに変換
h_m = h_cm / 100

# BMI計算
bmi = w_kg / (h_m ** 2)

# 小数点第2位まで表示（:.2f）
print(f"あなたのBMIは {bmi:.2f} です")

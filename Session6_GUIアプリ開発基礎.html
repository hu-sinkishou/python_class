GUIアプリ開発基礎

Tkinterでデスクトップアプリを作る

0. はじめに：CUIからGUIへ

これまでは、黒い画面に文字が出るだけの「CUI (Character User Interface)」でした。
今日からは、皆さんが普段使っているような、ウィンドウ、ボタン、メニューを持つ「GUI (Graphical User Interface)」アプリを作ります。

環境について

GUIアプリは画面を描画するため、Google Colab（サーバー）では動作しません。
ここからは皆さんのPC（ローカル環境）にインストールされたPython（VS Codeなど）で実行してください。

1. Tkinterをはじめよう

最小構成のウィンドウ

Pythonには標準で Tkinter（ティーキンター） というGUIライブラリが入っています。
まずは空っぽのウィンドウを表示してみましょう。

import tkinter as tk

# 1. 土台（メインウィンドウ）を作る
root = tk.Tk()
root.title("初めてのアプリ")
root.geometry("400x300")  # 幅x高さ

# 2. アプリを起動する（待機状態にする）
root.mainloop()

mainloopとは？

GUIアプリは、「ユーザーがボタンを押すまで待つ」必要があります。
mainloop() は「ウィンドウが閉じられるまで、プログラムを終了せずに待機し続けろ」という命令です。
これを書かないと、ウィンドウが一瞬で消えてしまいます。

2. ウィジェット（部品）の基本

部品を作る→置く

画面上のパーツを「ウィジェット」と呼びます。ウィジェットは「作って」から「配置する」の2ステップで表示されます。

ウィジェット名 役割 コード例
Label 文字や画像を表示する tk.Label(root, text="...")
Button 押せるボタン tk.Button(root, text="...")
Entry 1行の入力欄 tk.Entry(root) 
import tkinter as tk
root = tk.Tk()
root.geometry("300x200")

# 1. 部品を作る (Master=親ウィンドウ を指定)
lbl = tk.Label(root, text="こんにちは！", font=("Helvetica", 20))
btn = tk.Button(root, text="閉じる")

# 2. 部品を配置する (pack)
lbl.pack()
btn.pack()

root.mainloop()

3. レイアウト管理 (Geometry Manager)

3つの配置方法

部品をどこに置くかを決める方法（ジオメトリマネージャ）には3種類あります。

1. Pack（パック）

上から順に、ブロックのように積み上げていく方法。一番簡単でよく使います。

btn1.pack(side=tk.TOP)    # 上に詰める（デフォルト）
btn2.pack(side=tk.LEFT)   # 左に詰める
btn3.pack(pady=10)        # 縦に10pxの隙間を空ける

2. Grid（グリッド）

Excelのように「行(row)」と「列(column)」を指定して配置する方法。電卓のようなレイアウトに最適です。

# 0行目の0列目
btn1.grid(row=0, column=0)
# 0行目の1列目
btn2.grid(row=0, column=1)

3. Place（プレイス）

「x=100, y=50」のように座標を直接指定する方法。画面サイズが変わると崩れるので、あまり使いません。

4. フレーム (Frame) によるグループ化

複雑なレイアウトのために

「上のエリアにはボタンを横並び、下のエリアには画像を」といった配置をする場合、透明な箱である Frame を使います。

# 上部のフレーム
top_frame = tk.Frame(root)
top_frame.pack()

# 下部のフレーム
bottom_frame = tk.Frame(root)
bottom_frame.pack(side=tk.BOTTOM)

# ボタンは「top_frame」の中に配置する！
btn1 = tk.Button(top_frame, text="A")
btn1.pack(side=tk.LEFT)
